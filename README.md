# ゆうちゃんの足し算あそび 🎯

4歳児向けのヌマーカステンを使った足し算練習サイトです。

## 特徴

- ボールが1段5個ずつ入る箱で視覚的に数を学べます
- 1～10個のランダムな数のボールが表示されます
- 大きな数字ボタンでタブレットでも操作しやすく設計されています
- 正解すると自動的に次の問題に移行します

## 使い方

1. `numicon-addition.html` をブラウザで開く
2. 表示されたボールの数を数える
3. 1～10の数字ボタンから答えを選ぶ
4. 正解すると「正解！」と表示され、2秒後に次の問題に自動移行

## ファイル構成

- `numicon-addition.html` - メインのHTMLファイル
- `numicon-style.css` - スタイルシート
- `numicon-script.js` - JavaScriptファイル

## ライブデモ

GitHub Pagesで公開する場合は、Settings → Pages から有効化してください。
